# Security Policy


## Supported Versions
Only the latest released version of each package receives security fixes.


## Reporting a Vulnerability
Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately via [GitHub Security Advisories][1]. Include as much information as
possible to help reproduce and assess the issue:

- The affected package and version
- A description of the vulnerability and its potential impact
- Steps or a code sample to reproduce the issue

You should receive an acknowledgment within a few days. Once the issue is confirmed, a fix will be
prepared and released, and the advisory will be published after the fix is available.


[1]: https://github.com/d5hu/utilities/security/advisories/new
