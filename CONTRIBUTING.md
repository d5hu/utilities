# Contributing to D5HU.Utilities
Thank you for your interest in contributing! This document describes how to do so.


## General
If you are unsure about something, feel free to ask in the [Discussions][1].


## Bug Reports
If you encounter a problem or a defect:

1. **Prepare**
   - Check if an [Issue][2] already exists for your bug.
   - Find a minimal way to reproduce the issue.

2. **Report**
   - Create a new [Issue][2] with the "Bug Report" template.
   - Be patient and ready to provide additional information if needed.


## Feature Requests
If you have an idea for a new feature or an improvement:

1. **Prepare**
   - Check if an [Issue][2] already exists for your feature.
   - Consider how the feature would fit into the existing API and design.

2. **Request**
   - Create a new [Issue][2] with the "Feature Request" template.
   - Be patient and ready to provide additional information if needed.


## Pull Requests
If you want to contribute code:

1. **Prepare**
   - There must be an [Issue][2] for the task you want to work on.
   - Let the people within the [Issue][2] know if you plan to work on this task. Best is when you
     get assigned to the issue.

2. **Fork:** [Fork][10] the `main` branch.

3. **Code:** While working on the change, consider:
   - For each change, also unit tests must exist. (TDD is a good thing for resolving bugs.)
   - Ensure that all unit tests pass.
   - Use `dotnet format` before committing to ensure that the code is formatted correctly.

4. **Submit**
   - Create a [pull request][11] to this repository. The pull request must refer the issue you where
     working on.
   - Be patient and ready to do adjustments to your change if needed.


## Use of AI
Feel free to use AI tools to assist you in your contributions but be aware that the same rules
apply as if you were writing the code yourself.
